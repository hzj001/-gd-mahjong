# 音频资源（可选）

未放置 mp3 时，游戏会自动使用 **WebAudio 程序化音乐**（大厅舒缓五声、牌桌轻快节奏）与合成音效。

## 推荐文件（放入本目录后自动优先播放）

| 文件 | 用途 |
|------|------|
| `bgm_lobby.mp3` | 大厅背景音乐 |
| `bgm_table.mp3` | 牌桌背景音乐 |
| `sfx_click.mp3` | 按钮点击 |
| `sfx_draw.mp3` | 摸牌 |
| `sfx_discard.mp3` | 出牌 |
| `sfx_peng.mp3` | 碰 |
| `sfx_gang.mp3` | 杠 |
| `sfx_win.mp3` | 胡牌 |

建议使用无版权或已授权音乐，时长 1–2 分钟可循环，码率 64–128kbps 以控制包体。
